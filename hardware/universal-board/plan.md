# `PROTO-02` の実装の計画（未実装）

**これは実装の計画であり、未実装である。完成図ではない。**#405 のはんだ付けはこの計画に従い、付けた後に現物と照合して完成図にする（[hardware/README.md](../README.md)）。この文書は通電の許可ではない。通電の条件は [power-budget.md](../../docs/hardware/power-budget.md) が持つ。

## データの形式と正本

- **正本は KiCad の基板ファイル [`../deskcat.kicad_pcb`](../deskcat.kicad_pcb)** である（回路図 [`../deskcat.kicad_sch`](../deskcat.kicad_sch) と同じ KiCad project）。部品の footprint は project の library [`../DeskCat.pretty/`](../DeskCat.pretty)、記号は [`../DeskCat.kicad_sym`](../DeskCat.kicad_sym) にある。編集は KiCad で行う。
- 既製のユニバーサル基板なので、銅のパターンは作らない。基板ファイルの上では、はんだ面に沿わせる `111641` の芯線を `B.Cu` の配線（幅 0.75 mm）として、基板の穴を `Dwgs.User` の円として描いている。部品の足は基板の穴の位置に置いた。
- 図 [`plan-front.svg`](plan-front.svg)（部品面）と [`plan-back.svg`](plan-back.svg)（はんだ面。左右を裏返した向き）は、KiCad から書き出した派生物で、手で直さない。書き出しは `kicad-cli pcb export svg`（部品面は `F.Cu,F.SilkS,F.Fab,Edge.Cuts,Dwgs.User,Cmts.User`、はんだ面は `B.Cu,Edge.Cuts,Dwgs.User` に `--mirror`。どちらも `--page-size-mode 2 --exclude-drawing-sheet`）。
- 回路図との照合は KiCad の DRC で行う：`kicad-cli pcb drc --schematic-parity --severity-all hardware/deskcat.kicad_pcb`。2026-11-15 に、DRC の違反 0、未接続 0、回路図との食い違い 0 を確かめた（KiCad 8.0.9）。2026-11-23 に部品を角の塊へ寄せた配置へ更新し（大電流の経路と導体の長さを短くした。部品面の上の段に J6・J7 と母線、下の段に J5・F1・Q1、J8 は塊の下の辺）、同じ DRC で違反 0、未接続 0、食い違い 0 を確かめた。部品の参照番号（`J5`〜`J8`、`F1`、`Q1`、`R18`）は回路図と同じである。

穴は（列, 行）で呼ぶ。列は胴の後ろから 1〜27、行は下（床の側）から 1〜17 である。図の外側に番号を振ってある。

## 基板の向き

- 胴の左の壁の内側に立てる（[enclosure-and-neck.md](../../docs/hardware/enclosure-and-neck.md)の`物理的な完成形`）。長辺（72）を前後に、短辺（47.5）を上下にする。
- 部品面を胴の内側へ、はんだ面を壁の側へ向ける。部品面から見て左が胴の前、右が後ろになる。
- 基板は四隅とも同じ形なので、どちらを上にしても穴の並びは同じである。下にした辺を、はんだ付けの前に油性ペンで印す（部品面の下の縁。床の側）。

## はんだ面の導体

大電流の経路は `111641` の芯線（被覆を剥いた区間）を穴の上に沿わせ、通る穴ごとにはんだ付けする（図 `plan-back.svg` の太線）。**はんだだけで穴と穴を橋渡ししない。**分岐の節点の導体は `111641` が決める（power-budget.md の`HW-TBD-022を閉じるために残っていること`の2）。Gate の線（Q1 の G → R18 の足1）は電流が流れず、同じ芯線でよい。

- 入力の＋：J5＋ (2,12) → F1a (5,12)（行12）
- PTC の後：F1b (7,12) → Q1 D (10,12)（行12）
- 分岐点（5 V）：Q1 S (10,13) → (10,15)（列10。行15の母線へ上がる）。＋の母線は行15の (8,15) 〜 (16,15)。J6＋ (8,16)・J7＋ (13,16) の足は (8,15)・(13,15) へ1穴で上がる。(16,15) から (16,12) まで列16を下げて J8＋ (16,12) へつなぐ（J8 を付けるときだけ）。R18 の足の間の (15,15) を母線が通る
- GND：J5− (2,13) → (2,17)（列2）→ 行17の母線 (2,17) 〜 (17,17)。J6− (7,16)・J7− (12,16)・R18 の足2 (15,16) の足は (7,17)・(12,17)・(15,17) へ1穴で上がる（このうち J6− (7,16) と (7,17) を結ぶ短い線を W4a と呼ぶ）。(17,17) から (17,12) まで列17を下げて J8− (17,12) へつなぐ（J8 を付けるときだけ）
- Gate：Q1 G (10,11) → (15,11)（行11）→ R18 の足1 (15,14)（列15）
- Gate の戻り：R18 の足2 (15,16) → (15,17)（GND の母線の、J7− より右。star point (7,17) より右で、servo の電流が流れる (2,17)〜(7,17) の区間を通らない）

## 節点（回路図のラベル）

| 節点 | 何 | その点にある足 |
|---|---|---|
| `5V-IN` | 入力の＋（PTC の手前） | J5 ＋、F1 a（基板の外で M-12001 の＋） |
| `5V-PTC` | PTC の後（MOSFET の Drain） | F1 b、Q1 D |
| `5V-NODE` | 分岐点（MOSFET の Source の後の 5 V） | Q1 S、J6 ＋、J7 ＋、J8 ＋ |
| `Q1-GATE` | MOSFET の Gate（10 kΩ を通して GND へ） | Q1 G、R18 1 |
| `GND` | 共通 GND 戻り | J5 −、R18 2、J6 −、J7 −、J8 − |

電源経路は J5＋ → F1（PTC）→ Q1 の D → Q1 の S → 分岐点 → J6・J7・J8 の＋である。power-budget.md の`実装方法を決定した（2026-09-03）`の直列順序（端子台 → `PROT-OC-01` → `PROT-RP-01`（Drain を PTC 側、Source を分岐点側）→ 分岐点）をそのまま写した。Gate は R18（10 kΩ）を直列に通して GND へつなぐ（同節）。

分岐の順は、入力に近い方から servo（J6）、Pi（J7）、logic（J8）にした。**star point は（7,17）の節点とする**（J6− の足の穴 (7,16) から GND の母線へ上がる点）。servo の電流は GND の導体の（2,13）〜（2,17）〜（7,17）だけを流れ、Pi・Gate の取り出し口（12,17）（15,17）と logic の（17,17）との間を流れない。shunt（`MEAS-01`）を入れる場合は、W4a（(7,16)→(7,17)）の代わりに入れる。logic GND と servo GND の間に shunt が入っていないことは、#405 の受け入れ条件の電源 off の導通 check で確かめる。

Gate 抵抗 R18 の GND 側は、star point より右（(15,17)）で GND の母線へつなぐ（power-budget.md の`実装方法を決定した（2026-09-03）`の、Gate は共通 GND 戻り＝star point へ抵抗を介してつなぐ、という決定と、逆接の議論が Gate＝star point の電位を前提にしていること。Gate の電流は流れず、servo の電流が流れる区間を通らない）。Pi（J7−）・logic（J8−）・R18 の GND 側が、servo の経路（J6− → J5−）に最初に触れる点が star point であることは、[`check_star_point.py`](check_star_point.py) が基板ファイルを読んで確かめる（`python3 -I hardware/universal-board/check_star_point.py`。Q1 の 180 度の回転を読む）。

## 描かないもの

- `PSU-INGRESS-01`（Micro-B の変換基板）：2026-09-09 の案B で入力の経路から外れた（hardware-bom.md の `Not used`）。入力は J5 の端子台で受ける。
- ヒューズホルダ `110521`：2026-08-26 に方式を PTC へ変えたため使わない（`PROT-OC-01` は「ガラス管ヒューズ＋ホルダは採らない」）。PTC（F1）は基板へ直接はんだ付けする。
- shunt（`MEAS-01`）と `ADC-SHUNT`（GPIO32）の線：入れるかは #17・#405 で決める。入れる場合は W4a（(7,16)→(7,17)）の代わりに入れる（power-budget.md の`GND topology`の、servo の戻りだけが通る位置）。
- C1（servo の枝の bulk capacitor）：値と品が決まっていない（enclosure-and-neck.md の`決めていないこと`）。場所だけを空けた（J6 の左、列 3.3〜4.7・行 15〜17）。足の穴と、＋の導体 (4,15)〜(8,15) は品が決まってから足す。C1 の本体と Q1 の本体の上端の間は約 1.4 mm で、品が決まったら余裕を確かめる。

## 測る所（資料に寸法が無い）

測るのは人間である。現物は改変しない（[Hardware Safety Policy](../../docs/governance/hardware-safety-policy.md)の`測定は現物を改変しない`）。結果で穴の割り当てが変わる場合は、KiCad で基板ファイルを直し、DRC（回路図との照合を含む）を通してから図を書き出し直す。

| ID | 測る所 | 理由 |
|---|---|---|
| M1 | `2SJ334` の足が `PROTO-02` の穴（φ1.0）に入るか | datasheet の足の断面は 0.75 ± 0.15 角で、角の対角が公称で約 1.06 になり、穴径 1.0 を超えうる。挿して止まらずに入るかを、力を掛けずに当てて見る（曲げない・削らない） |
| M2 | `2SJ334` を挿したときの、基板の面から本体の上端までの高さ | 付け根の幅 1.1 の部分の長さは datasheet に最大 5.6 しか無く、本体が止まる高さが決まらない（上端は最大で約 20.9）。胴の中で左の壁から内側へ出る高さ（実機側の PM が照らす）に効く |
