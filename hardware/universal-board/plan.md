## 基板の向き

- 胴の左の壁の内側に立てる（[enclosure-and-neck.md](../../docs/hardware/enclosure-and-neck.md)の`物理的な完成形`）。長辺（72）を前後に、短辺（47.5）を上下にする。
- 部品面を胴の内側へ、はんだ面を壁の側へ向ける。部品面から見て左が胴の前、右が後ろになる。
- 基板は四隅とも同じ形なので、どちらを上にしても穴の並びは同じである。下にした辺を、はんだ付けの前に油性ペンで印す（部品面の下の縁。床の側）。

## はんだ面の導体

大電流の経路は `111641` の芯線（被覆を剥いた区間）を穴の上に沿わせ、通る穴ごとにはんだ付けする（図 `plan-back.svg` の太線）。**はんだだけで穴と穴を橋渡ししない。**分岐の節点の導体は `111641` が決める（下の`決めたこと`の A8）。Gate の線は電流が流れず、同じ芯線でよい。行番号の大きい側がふた側、小さい側が床側である（「行番号の大きい側／小さい側」と書く）。導体の折れ曲がりと通る穴は、すべて基板に実在する穴の上にある（四隅の (1,1)・(2,1)・(1,17)・(2,17) などは無い）。**はんだ面の芯線（導体）どうしは互いに交わらない**（異なる節点の導体が同じ穴を使わない。机上の自動配線と DRC で確かめた）。**部品面の絶縁した線（ジャンパー W2）は、はんだ面の導体と交わってよい**（別の面にあり、被覆がある）が、部品の足の穴・外形の上を通さない。部品の本体（外形 courtyard）の下を導体が通る所は、基板ファイルで数えると次のとおり：F1 の下は (13,6)（5V-NODE）、R18 の下は (5,5)（GND）、J5 の下は (3,12)（B と J5− の間）、J8 の下は 5V-LOGIC と GND の各 2 穴、J7 の下は 5V-LOGIC と GND の各 2 穴、J6 の下は (16,11)（A）、C1 の下は 5V-SERVO 2 穴と GND 1 穴、C2 の下は (21,4)（5V-SERVO）、R20 の下は GND の導体 21 穴。Q1・F2 の下には導体が無い。

- 入力の＋（`5V-IN`）：J5＋ (2,11) → (2,9)（列2を行番号の小さい側へ。ジャンパー W2 の端）。Q1 D (7,5) → (9,5)（行5を右へ。W2 のもう一方の端）。**この 2 つの導体は、W2（部品面の絶縁した線）でつなぐ**
- Gate（`Q1-GATE`）：Q1 G (7,4) → (6,4) → (6,6) → R18 の足1 (5,6)
- 分岐点（5 V、`5V-NODE`）：Q1 S (7,6) → 行6を右へ (12,6)（F1 a）→ (13,6)・(13,5) → 行5を右へ (17,5)（F2 a）
- logic の枝（`5V-LOGIC`）：F1 b (14,6) → (14,7) → 行7を左へ (9,7) → (9,8)（J8＋）。(14,7) → 列14を行13まで → 行13を右へ (20,13) → (20,14)（J7＋）
- servo の枝（`5V-SERVO`）：F2 b (19,5) → (20,5) → (20,4) → 行4を右へ (22,4)（C2＋）。(20,5) → 列20を行9まで（C1＋ (20,9)）→ (20,10) → 行10を左へ (18,10) → (17,10)（J6＋）
- servo の側の node A（`ADC-SHUNT`）：J6− (16,10) → (16,12) → (15,12)（R20 の足1 A）。**出口 W1 (15,11)** は (15,12) の隣の穴。**A の node には J6−・R20 の足1・W1 だけがつく**（C1・C2 の−は A に無い）
- GND（**star point の node は B (4,12) と J5− (2,12)、その間の (3,12)**）：J5− (2,12) → (4,12)（行12。2 穴）。**R18 の足2 (5,4) → (5,5) → (4,5) → 列4を行12まで（B の穴へ直接、上から）**。J8− (10,8) → (10,9) → 行9を左へ (9,9) → 列9を行12まで → 行12を左へ (5,12) → (4,12)（B へ右から）。J7− (19,14) → 行14を左へ (4,14) → (4,12)（B へ下から）。**C1−・C2−**：C2− (22,6) → 列22を行11まで → 行11を左へ C1− (20,11)。C1− の (21,11) から列21を行15まで → 行15を左へ (3,15) → 列3を行12まで → (3,12)（B と J5− の間の node の途中へ下から）。**導体（J8−・R18・J7−・C の−の 1 本。C1− と C2− は1本を共有）は互いに穴を共有しない**（下の`GND の並び`）

## 節点（回路図のラベル）

| 節点 | 何 | その点にある足 |
|---|---|---|
| `5V-IN` | 入力の＋（Q1 の手前。PTC は無い） | J5 ＋、Q1 D、W2（基板の外で M-12001 の＋） |
| `5V-NODE` | 分岐の節点（Q1 の Source の後。PTC の手前） | Q1 S、F1 a、F2 a |
| `5V-LOGIC` | logic の枝（F1 の後） | F1 b、J7 ＋、J8 ＋（基板の外で Pi の `PWR IN`、ESP32 の `5V` pin、`ADC-5V` の分圧） |
| `5V-SERVO` | servo の枝（F2 の後） | F2 b、J6 ＋、C1 ＋、C2 ＋（基板の外で servo の赤） |
| `Q1-GATE` | MOSFET の Gate（10 kΩ を通して star point へ） | Q1 G、R18 1 |
| `ADC-SHUNT` | shunt の servo の側の端 A の node（`GPIO32`）。C1・C2 の−は含まない | R20 足1、J6 −、W1 |
| `GND` | shunt の star の側の端 B から先の共通 GND 戻り | R20 足2、J5 −、J7 −、J8 −、R18 2、C1 −、C2 − |

電源経路は J5＋ → Q1 の D → Q1 の S → 分岐の節点 `5V-NODE` → **F1（PTC）→ logic の枝（J7・J8 の＋）**、**F2（PTC）→ servo の枝（J6 の＋、C1・C2 の＋）**である。**PTC は枝ごとに 1 個で、共有しない**（servo が拘束されて電流を引き続けても、切れるのは F2 だけで、Pi と ESP32 の電源は切れない）。Q1 は共通で、PTC の前（J5＋のすぐ後）に入る。直列の順（power-budget.md の`実装方法を決定した（2026-09-03）`）が「PTC が MOSFET の前」から「MOSFET が PTC の前」へ変わった理由と、残る危険は、下の`決めたこと`の A15 に書く。

**GND の並び（power-budget.md の`GND topology`）：**shunt は servo の戻り専用で、star point と servo GND 端子（J6−）の間だけに入れる。**star point は B（R20 の足2 (4,12)）の node** で、J5−（5 V ingress の GND）は B の 2 穴隣の (2,12) に、短い導体（(2,12)〜(4,12)）でつながる。**Pi の GND（J7−）・ESP32 の GND（J8−）・Gate の戻り（R18 の足2）・C1・C2 の−は、Pi・ESP32・R18 と共有しない別々の導体で B の node へ直接つく**（上の GND の項。C1 と C2 の−は1本を共有する）。servo の戻りは J6− → A → R20 → B と流れ、B で初めてほかの GND に合流する。**C1・C2 の−を A でなく B の側につけたのは、servo の過渡電流が J6− → A → shunt → B → C− と流れ、shunt を必ず通るため**（power-budget.md の`GND topology`。容量を shunt の ADC logging で決める方法に合う）。**B と J5− の間の短い導体（5.08 mm）には、全部の戻り（servo・Pi・ESP32・Gate・C の−）が一緒に流れる。J7−・J8−・R18 の足2 の導体には servo の電流は流れない。C1・C2 の−の導体には、コンデンサの充放電の電流（servo の過渡電流の一部）が流れる。R18 の足2 の導体は B の穴に直接つく**（B と J5− の間の導体の途中につかない。check_star_point.py が確かめる）。**Pi の GND・ESP32 の GND は、B の node で直接つながる。UART の GND の線（X3）があるので、Pi GND → J7− → B → J8− → X5 → B1 の GND → X3 → Pi GND の輪はできる。そこへ servo の電流は流れないが、Pi の戻りの一部が J8− と X5 を通る。**この輪をなくすための X3 の変更は、#446 の決定のとおり行わない。ADC-SHUNT は A の node を B（＝ESP32 の GND の node）を基準にして単端測定する。これらは [`check_star_point.py`](check_star_point.py) が基板ファイルを読んで確かめる（`python3 -I hardware/universal-board/check_star_point.py`。向きは 90 度の倍数を読む）。

## F1・F2 と Q1 の間隔

F1・F2 と Q1 の本体（資料の外形）の間は 3 mm 以上にする（PM の判断）。資料の寸法は、`MF-R135` が幅 A 最大 8.9 mm（足の間隔 5.08 mm の中央に置く）、`2SJ334` が本体の厚み 4.5 mm（足の列の両側へ 2.25 mm）である。Q1 は列7。
- F1：a (12,6)・b (14,6) なので中心は列13。間隔 ＝ (13 − 7) × 2.54 − 8.9 ÷ 2 − 4.5 ÷ 2 ＝ 15.24 − 4.45 − 2.25 ＝ **8.54 mm**（3 mm 以上）。
- F2：a (17,5)・b (19,5) なので中心は列18。間隔 ＝ (18 − 7) × 2.54 − 4.45 − 2.25 ＝ 27.94 − 6.70 ＝ **21.24 mm**（3 mm 以上）。

## C1 の 3 個目

2 個で足りず 3 個目が要る場合（power-budget.md は 2〜3 個を想定）は、**C3** を C2 の右の空き（列24、行8〜10）に立てて挿す。足は＋ (24,8)、− (24,10)（足を行方向に並べ、− が行番号の大きい側）。足す導体は、＋ (24,8)→(23,8)→(23,7)→(23,6)→(23,5)→(22,5)→(22,4)（C2＋ の `5V-SERVO` へ）と、− (24,10)→(23,10)→(22,10)（C の−の導体の列22へ）の穴だけで、**今ある導体は外さない**（これらの穴は今は使っていない）。C3 の外形（courtyard）は、ほかの部品の外形と重ならない。3 個目の部品の追加は、回路図に C3 を足し、基板ファイルへ置いて DRC を通す作業で、#405 の実測の結果で行う。
