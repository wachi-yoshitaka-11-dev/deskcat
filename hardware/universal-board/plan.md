## はんだ面の導体

大電流の経路は `111641` の芯線（被覆を剥いた区間）を穴の上に沿わせ、通る穴ごとにはんだ付けする（図 `plan-back.svg` の太線）。**はんだだけで穴と穴を橋渡ししない。**分岐の節点の導体は `111641` が決める（下の`決めたこと`の A8）。Gate の線は電流が流れず、同じ芯線でよい。行番号の大きい側がふた側、小さい側が床側である（「行番号の大きい側／小さい側」と書く）。導体の折れ曲がりと通る穴は、すべて基板に実在する穴の上にある（四隅の (1,1)・(2,1)・(1,17)・(2,17) などは無い）。**どの導体も互いに交わらない**（異なる節点の導体が同じ穴を使わない。机上の自動配線と DRC で確かめた）。部品の本体（外形 courtyard）の下を導体が通る所は、基板ファイルで数えると次のとおり：F1 の下は (6,7)（R18 の足2 の GND の導体）、Q1 の下は (10,5)（Gate）と (10,9)（J8− の GND）、R20 の下は行10〜14の GND の導体 23 穴（J8−・J7−・C の−・R18 の枝）、J5 の下は (3,12)（B と J5− の間）、J6・J7・J8・C1・C2 の下はそれぞれの 5 V と GND の枝の穴。R18 の下には導体が無い。

- 入力の＋（`5V-IN`）：J5＋ (2,11) → (2,7)（列2を行番号の小さい側へ）→ F1a (5,7)（行7）
- PTC の後（`5V-PTC`）：F1b (7,7) → Q1 D (10,7)（行7）
- 分岐点（5 V、`5V-NODE`）：Q1 S (10,8) → (12,8) → (12,7) → 行7を右へ (17,7)（C2＋）→ (21,7)（C1＋）。(16,7) から列16を行10まで → (17,10) → (17,12)（J6＋）→ 行12を右へ (20,12) → (20,13)（J7＋）。J8＋ (12,8) は Q1 S の導体の隣の穴
- servo の側の node A（`ADC-SHUNT`）：J6− (16,12) → (15,12)（R20 の足1 A）。**出口 W1 (15,10)** は (15,12)→(15,11)→(15,10)。**A の node には J6−・R20 の足1・W1 だけがつく**（C1・C2 の−は A に無い）
- GND（**star point の node は B (4,12) と J5− (2,12)、その間の (3,12)**）：J5− (2,12) → (4,12)（行12。2 穴）。**R18 の足2 (8,3) → (6,3) → 列6を行8まで → (4,8) → 列4を行12まで（B の穴へ直接、上から）**。J8− (13,8) → (13,9) → 行9を左へ (5,9) → 列5を行12まで → (4,12)（B へ右から）。J7− (19,13) → 行13を左へ (4,13) → (4,12)（B へ下から）。**C1−・C2−**：C2− (17,9) → 行9を右へ C1− (21,9) → 列21を行14まで → 行14を左へ (3,14) → 列3を行12まで → (3,12)（B と J5− の間の node の途中へ下から）。**導体（J8−・R18・J7−・C の−の 1 本。C1− と C2− は1本を共有）は互いに穴を共有しない**（下の`GND の並び`）
- Gate（`Q1-GATE`）：Q1 G (10,6) → (10,5) → R18 の足1 (8,5)

| 節点 | 何 | その点にある足 |

| `5V-PTC` | PTC の後（MOSFET の Drain） | F1 b、Q1 D |
| `5V-NODE` | 分岐点（MOSFET の Source の後の 5 V） | Q1 S、J6 ＋、J7 ＋、J8 ＋、C1・C2 ＋ |

電源経路は J5＋ → F1（PTC）→ Q1 の D → Q1 の S → 分岐点 → J6・J7・J8 の＋である。power-budget.md の`実装方法を決定した（2026-09-03）`の直列順序をそのまま写した。

**GND の並び（power-budget.md の`GND topology`）：**shunt は servo の戻り専用で、star point と servo GND 端子（J6−）の間だけに入れる。**star point は B（R20 の足2 (4,12)）の node** で、J5−（5 V ingress の GND）は B の 2 穴隣の (2,12) に、短い導体（(2,12)〜(4,12)）でつながる。**Pi の GND（J7−）・ESP32 の GND（J8−）・Gate の戻り（R18 の足2）・C1・C2 の−は、Pi・ESP32・R18 と共有しない別々の導体で B の node へ直接つく**（上の GND の項。C1 と C2 の−は1本を共有する）。servo の戻りは J6− → A → R20 → B と流れ、B で初めてほかの GND に合流する。**C1・C2 の−を A でなく B の側につけたのは、servo の過渡電流が J6− → A → shunt → B → C− と流れ、shunt を必ず通るため**（power-budget.md の`GND topology`。容量を shunt の ADC logging で決める方法に合う）。**B と J5− の間の短い導体（5.08 mm）には、全部の戻り（servo・Pi・ESP32・Gate・C の−）が一緒に流れる。J7−・J8−・R18 の足2 の導体には servo の電流は流れない。C1・C2 の−の導体には、コンデンサの充放電の電流（servo の過渡電流の一部）が流れる。R18 の足2 の導体は B の穴に直接つく**（B と J5− の間の導体の途中につかない。check_star_point.py が確かめる）。**Pi の GND・ESP32 の GND は、B の node で直接つながる。案Bの構成では、gpio-assignment.md の条件5との関係が #405 で決まるまで、X3（UART の GND の線）と UART の信号線をつながない**（power-budget.md の`ESP32の給電経路`）。**X3 をつなぐ構成になったときは、Pi GND → J7− → B → J8− → X5 → B1 の GND → X3 → Pi GND の輪ができる（servo の電流は流れないが、Pi の戻りの一部が J8− と X5 を通る）。この輪の扱い（X3 の変更をするか）は、#405（条件5）と #803（`HW-TBD-036`）が持つ。**ADC-SHUNT は A の node を B（＝ESP32 の GND の node）を基準にして単端測定する。これらは [`check_star_point.py`](check_star_point.py) が基板ファイルを読んで確かめる（`python3 -I hardware/universal-board/check_star_point.py`。向きは 90 度の倍数を読む）。

## F1 と Q1 の間隔

F1 と Q1 の本体（資料の外形）の間は 3 mm 以上にする（PM の判断）。資料の寸法は、F1（`MF-R135`）が幅 A 最大 8.9 mm（足の間隔 5.08 mm の中央に置く）、Q1（`2SJ334`）が本体の厚み 4.5 mm（足の列の両側へ 2.25 mm）である。F1 は a (5,7)・b (7,7) なので中心は列6、Q1 は列10。間隔 ＝ (10 − 6) × 2.54 − 8.9 ÷ 2 − 4.5 ÷ 2 ＝ 10.16 − 4.45 − 2.25 ＝ **3.46 mm**（3 mm 以上）。Q1 を列9にすると 0.92 mm で足りない。

## C1 の 3 個目

2 個で足りず 3 個目が要る場合（power-budget.md は 2〜3 個を想定）は、**C3** を C1 の右下の空き（列23、行11〜13）に立てて挿す。足は＋ (23,11)、− (23,13)（足を行方向に並べ、− が行番号の大きい側）。足す導体は、＋ (23,11)→(22,11)→(22,10)→(22,9)→(22,8)→(21,8)→(21,7)（C1＋ の `5V-NODE` へ。(21,8) は C1 の足の間の穴）と、− (23,13)→(22,13)→(21,13)（C の−の導体の列21へ）の穴だけで、**今ある導体は外さない**（これらの穴は今は使っていない）。C3 の外形（courtyard）は、ほかの部品の外形と重ならない。3 個目の部品の追加は、回路図に C3 を足し、基板ファイルへ置いて DRC を通す作業で、#405 の実測の結果で行う。
