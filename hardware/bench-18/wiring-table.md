## 負荷（N2 と N3 の間）

窓の (D)・(B) と段1は、同じ2本の jumper wire の負荷側の針に、別の物をつなぐ。**両端メスの jumper wire は窓の (D)・(B) の間だけ使い、段1では外して servo の plug を jumper wire の針に挿す。**メス側の接点はハウジングの中にあり、プローブが届かない。

- **窓の (D)・(B)：**赤い jumper wire の針（負荷側、N2） → 両端メスの jumper wire（赤側） → `MEAS-01` の予備（セメント抵抗。赤側の足 → 茶側の足） → 両端メスの jumper wire（茶側） → 茶の jumper wire の針（負荷側、N3）
- **段1：**赤の jumper wire の針（負荷側、N2） → servo の plug の赤 → （servo 本体） → servo の plug の茶 → 茶の jumper wire の針（負荷側、N3）
