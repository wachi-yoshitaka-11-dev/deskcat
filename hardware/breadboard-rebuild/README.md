## 使う板

手持ちの `PROTO-01`（[BOM](../../docs/hardware/hardware-bom.md)）だけを使う。購入は要らない。

| ID | 板 | 載せるもの |
|---|---|---|
| B1 | EIC-3901（6穴版） | ESP32、ESP32 の J2 側の pull、3V3／GND の電源列、UART とサーボ信号の直列抵抗、LED 2枝、ADC-5V の分圧 |
| B2 | BB-601（1枚目） | 首を通る LCD の14本の受け口、LCD 側の pull（CS・RST・T_CS・BL） |
| B3 | BB-601（2枚目） | `ENV-01`、`ACCEL-01`、ADC-3V3 の分圧 |

今の配線に使っている a〜j 行・30列の板は使わない（型番が記録に無い）。B2 は B1 の上の辺（J3 の側）に並べて置き、J3 から B2 への線（S5〜S12）を短くする。B3 の置き場所は仮筐体で決める。

## 配置の考え方

1. **ESP32 の向き。**EIC-3901 に挿すと、片側に1穴、反対側に2穴が残る（ユーザーの申告と写真）。電源列は下側の1組だけなので、2穴の側を電源列の側に置く。J2（3V3・GND・I2C・SERVO-PWM）を下の J 行に、J3 を上の B 行にし、USB を板の端（30列の側）に出す。この向きで、J2-1（3V3）、J2-9・10（I2C）、J2-11（GPIO27）、J2-14（GND）の列が電源列の穴の列（1〜6・9〜14・17〜22・25〜30）とそろい、pull 抵抗と電源の硬いジャンパーを L 行から電源列へ縦にまっすぐ挿せる。アンテナの下と近く（9〜11列）は使わない。
2. **J3 側は1穴しか残らない。**LCD の CS・RST・T_CS の pull-up と BL の pull-down は、ESP32 の脇ではなく B2（LCD の受け口の板）に置く。同じ導体の上の位置が変わるだけで、論理接続は今と同じである。
3. **LCD の14本。**首を通す線は、[enclosure-and-neck.md](../../docs/hardware/enclosure-and-neck.md) の `仮筐体` のとおり両端メスのジャンパー線14本である。LCD 側は module のピンに挿す。胴側は、手持ちの細ピンヘッダ（`PROTO-01`）を1本ずつに切り離して B2 の穴に立て、メスの端をそこへ挿す。SCK と T_CLK、SDI と T_DIN、SDO と T_DO は同じ列に挿して共有する（[#34 の決定](https://github.com/wachi-yoshitaka-11-dev/deskcat/issues/34#issuecomment-5864974935)、[enclosure-and-neck.md](../../docs/hardware/enclosure-and-neck.md) の `頭と胴の14線`）。これで共有のためのジャンパーが要らない。
4. **センサーを別の板にする。**B3 は ESP32 と Pi から離して胴に固定できる。`ENV-01` を Pi の熱から離すこと、`ACCEL-01` を胴に固定すること（[enclosure-and-neck.md](../../docs/hardware/enclosure-and-neck.md)）に合わせられる。B3 の置き場所は仮筐体で決める。
5. **短絡しにくさ。**硬いジャンパーと抵抗・LED は縦か横の直線だけにし、両端の間の穴を空け、互いに交差させない（`generate.py` が検査する）。長い距離と板をまたぐ所は柔らかい線にする。5 V は ESP32 の 5V pin から ADC-5V の分圧へ行く S18 だけで、行き先の B1 G8 の列（下半分の8列）は電源列の穴が無い列で、下半分の両隣（7列と、使わない9列）は空けてある。`generate.py` は、5 V の導体に触れる部品が R11（先は GPIO33）だけで、GPIO33 には R11 と R12（先は GND）だけが触れること、5 V の列の両隣に ESP32 自身のピン以外が無く、その上をほかの部品が通らないこと、板の外へ出る線にサーボの電源と Pi の給電が無いことを検査する。
6. **大電流はブレッドボードを通さない。**サーボの電源と GND の戻り、Pi の給電、`MEAS-01` の shunt はブレッドボードに載せない（[power-budget.md](../../docs/hardware/power-budget.md) の `大電流経路にbreadboard接点とジャンパー線を使わない`、BOM の `PROTO-01`）。サーボを ESP32 から給電しない。ブレッドボードを流れるのは信号と、ESP32 の `3V3` pin から取る小電流の枝と、ADC-5V の分圧の電流（5V pin から 10 kΩ＋10 kΩ）だけである。
7. **論理接続は変えない。**載せる回路は今の記録（基準図、EXP-022、EXP-025、EXP-028、EXP-038）と同じ節点の組である。この設計が KiCad 回路図（`../deskcat.kicad_sch`）の更新を新たに要することは無い。測定器の線（`MEAS-02` の Arduino）と、今つながっていない GPIO32 の線は載せない（`wiring-table.md` の `載せないもの`）。

## 残った `TBD`

- **ACCEL-01 の上段4本の行。**2列の間隔は、記録にもメーカーの資料にも無い（秋月の商品ページは404。ユーザーは実機が手元に無く分からないと回答）。写真の比では約5〜6ピッチに見えるが、斜めからの写真なので値にしない。下段を溝のすぐ下の f 行に置くので、溝の幅が3ピッチなら、間隔が3〜6ピッチのとき上段は e〜b 行に来て、上に空き穴が1つ以上残り、この配置で組める。7ピッチ以上（上段が a 行かそれより外）なら組めないので、止めて設計を直す。上段の列（2〜5列）も写真の読みで、挿すときに確かめる。
- **module の本体の大きさ。**`ENV-01` の本体を板の外へ出す向きで、ピンの名前の順が結線表と同じになるか。`ACCEL-01` の本体が B3 の10・11列（H9・H10）にかかるか。
- **溝の幅と電源列までの距離。**EIC-3901 は写真から、溝が3ピッチ、L 行から − の列が3ピッチ、＋ の列が4ピッチと読んだ（目安）。BB-601 の溝の幅は記録が無く、図は3ピッチで描いた。H1〜H4・H9・H10 の長さと、電源列へ下りる抵抗・LED の足の長さは現物で合わせる。
- **電源列の導通。**− の列（青）が全長でつながっていること、＋ の列（赤）が赤い部品で14〜17列の間をつながっていること。メーカーの説明は「赤い電源ラインは2系統に分けられる」だけで、青の列の分断については書いていない。
- **ESP32 が B 行と J 行に挿さること。**写真の挿し方（片側1穴・反対側2穴）と同じ間隔を、1行ずらした位置に取る。2穴の側が電源列の側になるように挿す。
- **硬いジャンパーの長さの在庫。**1ピッチ（H6）と6ピッチ（H7・H8）を含む。合う長さが無いものは柔らかい線に替える（論理接続は同じ）。
- **細ピンヘッダの残数。**首の14本の受けに14本要る。`PROTO-01` の 20P×5 は一部使用済みで、残りが足りるかは記録に無い。組むときに数える。
- **線の色。**柔らかい線の色は手持ちに合わせる。結線表の ID で識別する。

## 組み直しで気をつけること

- 組み直しは電源を切った状態で行う（ESP32 の USB、Pi、サーボの電源を外す）。初回通電と回路変更後の試験は人間が監視する（[Hardware Safety Policy](../../docs/governance/hardware-safety-policy.md)）。通電前の照合は実機側が行う。
- 通電の前に、ESP32 の向きを基板の silk で確かめる。J2-1（3V3）が B1 の J 行・12列、J2-19（5V）が J 行・30列、J3-1（GND）が B 行・12列に挿さっていること。向きは寸法図からの読みであり（`値と並びの出所`）、逆向き（180度回した向き）に挿すと、H1（3V3）が J3-19（CLK、flash 用）に、H2（GND）が J3-6（GPIO21）につながる。
- 組み直した直後に抜いておく線は、結線表の `組み直した直後` 欄にある（LED の GPIO の線、Pi との UART の線）。挿すのは、それぞれの正本の条件を満たしたときだけである。
- 組み直した後、実機側が実験記録の `Wiring revision` と `../breadboard/layout.svg` を同じ PR で更新する（[hardware/README.md](../README.md)）。そのとき、この配置から変えた所があれば、ここの `generate.py` も直す。
