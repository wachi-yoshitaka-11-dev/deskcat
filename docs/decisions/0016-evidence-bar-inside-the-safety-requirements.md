# ADR-0016: 安全要件の中で、判定に効く数と資格として求める数を分ける

> 状態: Accepted
> 日付: 2026-08-26

## 背景

[ADR-0014](0014-safety-requirements-and-general-values.md)は、一次資料または実測を要求する
範囲を安全要件5項目へ絞った。**どの分類に根拠が要るかは決めたが、その分類の中で何を根拠として
認めるかは決めていない。**

結果として、5項目に当たる値については**量産の型式認定と同じ水準**が残った。
[#205](https://github.com/wachi-yoshitaka-11-dev/deskcat/issues/205)の発注判断がその実例である。

**公開値が無いことだけを理由に止まった判断が5件ある。**

- 大東通信機 MF51NR の**遮断定格が非公開**
- ヒューズホルダ`110521`の**定格がdatasheetにも商品ページにも未記載**（康揚企業の図面は
  寸法と材質欄だけで、定格電流・定格電圧・接触抵抗のいずれも記載しない）
- `CABLE-PI-PWR-01`（秋月`109314`）の**許容電流もAWGも非公開**
- 東芝`2SJ334`の**`RDS(on)`が1 A付近で未規定**（`ID`=−15 Aで標準46 mΩ）

**`CABLE-PI-PWR-01`は、人間が個別に例外を宣言して通した**（#205の訂正⑧。
「人間がこの行へ公開を求めないと決めた」）。**規則が追いつかないため、1件ずつ人間が
例外を宣言する運用になっていた。**

**なお`WIRE-PWR-01`はこの型に見えて、実は公開値で埋まる。**秋月`111641`は住友電気工業の
イラックスA電線・導体断面積0.3054 mm²＝0.3 sqであり、**許容電流は住友電工が公開している**
（秋月が添付する`許容電流計算式`PDFの2ページ目、`イラックス®A電線（定格温度90℃）`の
`0.3 sq`曲線）。**この行はBではない。**

一方で、**同じ「値が足りない」でも却下が正しかった判断もある。**

- PTC`100507`は保持1.1 Aだが、**保持電流は温度で2〜3割下がる**ため定常1.0 Aで誤トリップする
- PTC`112629`／`101344`は**トリップが3.7／4.2 Aで、電源の3 Aでは切れない**
- MF51NR 2 Aは**保証点が3.2 A（1時間）／4.0 A（2分）で、3 Aがどちらにも届かない**
- MF51NR 1 Aは**`1.0 × 0.8 = 0.8 A`で、定常840 mAを上回らない**

**これらは試作でも同じ結論になる。切れないヒューズは保護ではない。**

## 判断要因

- **2種類が混ざっている。**片方は機能の成否を決め、もう片方は資格の提示でしかない
- **分かれ目は「その数を変えたら結論が変わるか」である。**部品の種類でも、公開元でもない
- 資格側は**桁の余裕で決着する。**1 Aを通す線材の許容電流は、公開されていなくても
  0.3sqなら桁で足りる
- **人間が既に個別判断でこの線を引いている**（訂正⑧）。規則にすれば、その判断を毎回
  求めずに済む
- **緩めると危ないのは機能側だけである。**そこは緩めない

## 検討した選択肢

### 選択肢A: 現状維持

5項目の中では公開された定格を要求し続ける。

**採らない。**上の5件が止まったままになる。人間が1件ずつ例外を宣言する運用が続く。
**本projectは学習とプロト開発であり、量産の型式認定の水準は目的に対して過剰である。**

### 選択肢B: 5項目からいくつかを外す

短絡や逆極性を安全要件から外し、要求そのものを消す。

**採らない。**帰結が破損または発火である項目を外すことになる。
**止まっている原因は項目の選定ではなく、根拠の水準である。**

### 選択肢C: 5項目の中で根拠の水準を2つに分ける

判定に効く数には実際の値を求め、資格として求めている数は桁の余裕で足りるとする。

## 決定

**選択肢Cを採る。**

1. **5項目の中でも、必要な根拠を2種類に分ける。**分かれ目は
   **「その数を変えたら結論が変わるか」**である
2. **A（判定に効く数）は実際の値を要する。**一次資料でも実測でもよい。
   **値が無いなら、その部品を使わない**
3. **B（資格として要求している数）は、公開されていないことだけを理由に却下しない。**
   経路の最悪値と比べて桁で余裕があることを示し、根拠と余裕を記録すれば足りる
4. **Bで済ませるときは4つを満たす。**比較する最悪値を実在する値で示す。余裕を数で書く。
   公開値が無いことと代わりの担保を記録する。**Aを代替しない**
5. **迷ったらAとして扱う**
6. 正本は[Hardware Safety Policy](../governance/hardware-safety-policy.md)の
   「5項目の中での根拠の水準」である
7. §2「必須の根拠」の「販売業者の掲載情報は十分な根拠にならない」は、**識別（どの品か）に
   対する規則**であることを明記する。定格の値についてはこの決定が種別ごとの要求を定める

**5項目そのものは変えない。**追加も削除もしない。

## 影響

### 利点

- **止まっていた5件が動く。**うち1件は人間が既に個別判断で通しており、**その判断が規則になる**
- **安全上の結論は変わらない。**#205の部品選定を新しい水準で再判定したが、
  採用する品（Littelfuse 218 Series 1.25 A）は同じである。2 A品は遮断定格を不問にしても
  **Aで落ちる（切れないため）**
- 人間が1件ずつ例外を宣言する運用が要らなくなる

### 欠点

- **AとBの振り分けは人が行う。**機械では判定できない
- **「桁で余裕」の線引きに幅がある。**1桁を目安としたが、境界の事例は判断になる
- 記録の量が増える。Bで済ませるたびに、比較した最悪値と余裕を書く

### リスクと対策

| リスク | 対策 |
|---|---|
| Aの数をBとして扱い、機能しない部品を通す | 分かれ目を「その数を変えたら結論が変わるか」と定義する。**迷ったらA**と明記する。#205の再判定を実例として残す |
| 「桁で余裕」が「たぶん大丈夫」に落ちる | **比較する最悪値を実在する値で示す**ことと**余裕を数で書く**ことを条件にする |
| Bで済ませた箇所が後から追えない | 公開値が無いことと代わりの担保の記録を条件にする |
| 5項目そのものを緩めたと読まれる | 決定本文とpolicyの両方へ「5項目は変えない」「gateの開閉とは別」と書く |
| 桁の余裕が実は無い経路を見落とす | 比較対象を**経路の最悪値**と定める。部品単体の定格ではない |

## 検証

**#205の判断を新しい水準で再判定した。**

| 判断 | 種別 | 新水準 |
|---|---|---|
| PTC`100507`（保持1.1 A、温度で低下） | A | **却下のまま** |
| PTC`112629`／`101344`（トリップ>3 A） | A | **却下のまま** |
| MF51NR 2 A（保証点に3 Aが届かない） | A | **却下のまま** |
| MF51NR 1 A（0.8 A < 定常840 mA） | A | **却下のまま** |
| MF51NRの遮断定格が非公開 | B | **これだけでは却下しない。**ただし**非公開の値と桁は比べられない。**言えるのは回路条件の側（250 V定格のヒューズを5 V・3 Aで遮断させる）である |
| ホルダ`110521`の定格が未記載 | B | **未記載であること自体は却下理由にしない。**ただし**通すには条件4つを満たす根拠が別に要る**（比較する実在値を、純正クリップの定格などから立てる）。現時点では未提示 |
| `CABLE-PI-PWR-01`の許容電流／AWG | B | **却下理由にしない**（人間が訂正⑧で同じ判断）。**根拠は別に要る。**`109314`は`電線外径3.8 mm`しか公開しておらず、導体側の実在値が要る |
| `2SJ334`の`RDS(on)`が1 A域で未規定 | B | **通る。**`ID`=−15 Aで標準46 mΩという実在値があり、1 A域は桁で余裕がある |

**Aの4件は却下のまま変わらない。Bの4件は「公開値が無い」を理由に却下しなくなる。**
**うち2件は、通すために根拠を書く必要が残る。それはこの決定が要求していることである。**

**Aの結論は採用する品によらない。**`02181.25HXP`は日本で入手できないと報告がある
（DigiKey日本は取り扱い終了、RS日本は218シリーズの1.25 Aを扱わない）。
**代替候補（Littelfuse`02391.25MXP`、冨士端子`FGMB250V1.25A`、日本製線`FSL 250V 1.25A`）は
いずれも1.25 Aであり、200 %＝2.5 Aに3 Aが到達するためAを満たす。**
**どれを買うかは人間の判断であり、この決定はそこへ影響しない。**

見直し条件: **Bとして通した箇所で、実際に破損または発熱が起きた場合はこの決定を改訂する。**
そのとき見るのは「桁の余裕という判断が甘かったのか」「AをBと振り分けたのが誤りだったのか」の
どちらかである。**policyの記述だけを変えない。**

## 置き換える決定

なし。**[ADR-0014](0014-safety-requirements-and-general-values.md)を置き換えない。**
同ADRが決めた5項目と、5項目以外を一般値で開始してよいことは維持する。
**この決定はその内側、5項目の中での根拠の水準を足すものである。**
